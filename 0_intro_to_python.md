## Suggested pace
- Standard pace: 1 lesson per day (about 2 to 3 weeks including review days).
- Fast pace: 2 lessons per day.
- Deep pace: 1 lesson every 2 days with extra practice.

For each lesson session:
1. Run the file once.
2. Read output and comments.
3. Edit values or starter code.
4. Re-run and compare results.
5. Answer the questions from memory.

## How to do the practice sections
- Complete each practice item directly inside that lesson file.
- Keep your edits below the original examples when possible.
- Test each practice change immediately.
- If a practice item has starter code, begin there first.

## How to self-check with answers_to_questions.md
- After finishing a lesson, answer its questions on your own first.
- Then open answers_to_questions.md and compare by file and question number.
- If your answer differs, re-run the lesson and find the exact concept in code.

## Practical learning tips
- Type code changes yourself instead of copy-paste.
- Make small changes and run often.
- Keep a short mistake log: bug, cause, fix.
- Revisit Lessons 7 to 10 and 15 if logic or debugging feels hard.
- Build one tiny personal project after Lesson 15 using functions, files, and tests.

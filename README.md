# 🎓 LearnPython 🎓

Teach yourself Python — 15 short, runnable lessons that build on each other.

Every lesson is a single `.py` file you run, read, edit, and re-run. Examples first, then practice items you complete in place, then questions to answer from memory. No frameworks, no setup, no dependencies.

## Quick start

You need Python 3.8+ (`python --version` to check).

```bash
git clone https://github.com/lllons/LearnPython.git
cd LearnPython
python 1_intro_to_python_basics.py
```

That's it — you're on Lesson 1. Read [`0_intro_to_python.md`](0_intro_to_python.md) for the full study guide and suggested pace.

## How to get the most out of it

1. **Run the file** and read the output alongside the comments.
2. **Change something** — a value, a condition, a loop bound — and run it again.
3. **Do the practice items** inside the lesson file, below the examples.
4. **Answer the questions** from memory before you look anything up.
5. **Check yourself** against [`answers_to_questions.md`](answers_to_questions.md), matched by file and question number.

If an answer surprises you, go back to the code and find the exact line that explains it.

A comfortable pace is one lesson a day, so roughly two to three weeks with review days. Two a day if you're moving fast, or one every two days if you'd rather go deep. After Lesson 15, build something tiny of your own that uses functions, files, and tests.
